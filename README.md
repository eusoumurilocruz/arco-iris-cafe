# Arco Íris Café · Cardápio digital

Cardápio interativo do Arco Íris Café, feito em um único arquivo `index.html`
(sem dependências: fotos, logo e animações já estão dentro do arquivo).

## Como ver
Abra o `index.html` no navegador, ou publique com o GitHub Pages:
**Settings → Pages → Branch: `main` / pasta `/ (root)` → Save.**

## O que tem
- Abertura animada com bonequinhos andando
- Cardápio completo: bebidas quentes e geladas, salgados, doces, kids, combos e eventos
- Seção Diversão, aviso do Tour e links do Instagram e WhatsApp
- Funciona em celular e se adapta a aparelhos mais simples

`qr_cardapio_arco_iris.png` é um QR Code de teste (precisa ser refeito com o endereço público do site).
